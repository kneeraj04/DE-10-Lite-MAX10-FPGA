# Project 06: Traffic Light Controller Using FSM on DE10-Lite FPGA

## 1. Title

Design and Implementation of a Single Road Traffic Light Controller Using Finite State Machine (FSM) on DE10-Lite FPGA


## 2. Objective

The objective of this project is to design and implement a single-road traffic light controller using a Finite State Machine (FSM) on the Terasic DE10-Lite FPGA board.

The traffic controller is designed using a Moore FSM with four states:

- S0: Green Light
- S1: Yellow Light
- S2: Red Light
- S3: Yellow Light

Each state remains active for a fixed duration of 2 seconds. A timer circuit is implemented using the FPGA clock to generate the required delay signal. This timer signal is used by the FSM to control state transitions.

The FSM was first designed using the Quartus State Machine File (.smf) editor and then converted into synthesizable VHDL code for FPGA implementation.


## 3. FSM File Creation and HDL Conversion

The traffic controller FSM was created using the Quartus State Machine File (.smf) editor.

A Moore FSM architecture was selected because the output signals depend only on the current state.

The FSM consists of four states:

State S0:
Green LED ON

State S1:
Yellow LED ON

State S2:
Red LED ON

State S3:
Yellow LED ON


State transition sequence:

S0 → S1 → S2 → S3 → S0


The FSM changes from one state to another when the input signal:

timer_done = '1'

is generated by the timer circuit.


After designing the FSM in the Quartus SMF editor, the design was converted into VHDL automatically.

The generated file:

Traffic_Controller.vhd


contains:

- FSM state declaration
- Current state register
- Next-state transition logic
- Moore output decoding logic


FSM Inputs:

- clock: FPGA clock signal
- reset: FSM reset signal
- timer_done: Timer trigger signal


FSM Outputs:

- Green
- Yellow
- Red


The generated FSM file only contains the state control logic. It does not include the timing generation circuit or FPGA hardware connections.


## 4. Traffic_Timer_Top.vhd and Difference from FSM File

The SMF-generated FSM requires a timing input:

timer_done


The FSM only controls the traffic light sequence and does not generate the delay between states.

Therefore, a separate top-level module was created:

Traffic_Timer_Top.vhd


The Traffic_Timer_Top module performs three main tasks:


### 1. Timer Generation

The DE10-Lite FPGA provides a 50 MHz onboard clock.

A counter-based timer was implemented to count clock cycles.

Calculation:

50 MHz × 2 seconds = 100,000,000 clock cycles


After reaching this count, the timer generates:

timer_done = '1'


for one clock cycle.

This signal triggers FSM state transitions:

S0 → S1 → S2 → S3 → S0


### 2. FSM Integration

The generated FSM module:

Traffic_Controller.vhd

is instantiated inside the top-level module.

The connection is:

Timer Circuit

        |

        |

   timer_done

        |

        |

Traffic_Controller FSM


### 3. FPGA LED Interface

The FSM output signals are connected to the DE10-Lite onboard LEDs:

Green  → LEDR0

Yellow → LEDR1

Red    → LEDR2


### Difference Between FSM File and Traffic_Timer_Top

Traffic_Controller.vhd:

- Generated automatically from SMF
- Contains only FSM logic
- Controls state transitions
- Uses timer_done as input
- Does not contain FPGA pin connections


Traffic_Timer_Top.vhd:

- Written manually in VHDL
- Contains timer circuit
- Generates timer_done signal
- Instantiates FSM module
- Connects FPGA clock and LEDs


Complete hardware structure:

              CLOCK_50
                  |
                  |
          +---------------+
          | Timer Counter |
          +---------------+
                  |
              timer_done
                  |
                  |
          +---------------+
          | Traffic FSM   |
          | S0-S1-S2-S3   |
          +---------------+
            |      |      |
            |      |      |
          LEDR0  LEDR1  LEDR2
          Green Yellow  Red

The FSM generated the correct traffic light sequence:

S0 → S1 → S2 → S3 → S0


Each state remained active for approximately 2 seconds.
